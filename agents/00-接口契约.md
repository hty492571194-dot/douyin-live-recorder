# 接口契约 v1 — 多智能体协作的唯一事实源

> 所有子智能体在动工前必读本文。**任何契约变更必须先改本文并提交 git，再改代码。** 契约未列出的接口属于实现细节，子智能体可自行决定。

## 1. Git 交接协议

- 仓库：项目根目录，阶段标签：`baseline` → `phase-a` → `phase-b` → `phase-c` → `phase-d`。
- 智能体 N 只能基于上一标签工作：`git checkout phase-x` 后开工；完成后 commit 并打自己的标签。
- **机械验收门（强制）**：打标签前必须执行 `bash scripts/verify.sh <phase>` 且退出码为 0；非 0 不得打标签、不得交接。该脚本由智能体 A 创建（见 01 子任务书 A7），后续智能体**只能追加**本阶段的检查块（以注释 `# --- phase-x ---` 分隔），不得删改前任的检查项（回归保护）。
- **严格串行**：不允许多个智能体同时写同一仓库。
- 每个任务一个 commit，message 格式：`A2: 配置校验与 monitors 动态生效`。

    # update_config 检测到 monitors 列表内容变化时 +1

## 3. HTTP API 契约（最终形态，phase-d 后全部就绪）

| 方法 路径 | 请求 | 响应 | 引入阶段 |
|---|---|---|---|
| GET `/api/config` | — | config dict（深拷贝） | 已有 |
| POST `/api/config` | patch dict | `{ok, error, restart_required}` | A2 改造 |
| GET `/api/status` | — | `{config, streamers, commands, nas}`（commands/nas 键 A5/C1 引入，缺失时为空值不省略） | A5/C1 扩展 |
| GET `/api/preflight` | — | `[{id,title,status:"ok"\|"warn"\|"fail",detail,action}]` | B2 |
| GET `/api/nas` | — | `{config(脱敏), mounted, backoff_s, queue_depth, last_archive}` | C3 |
| POST `/api/nas` | nas 配置 | `{ok, error}` | C3 |
| POST `/api/nas/test` | nas 配置（含密码） | `{ok, latency_ms, error}` | C3 |

- 所有 JSON 响应 UTF-8、`ensure_ascii=False`。
- 校验类错误一律 HTTP 400 + `{ok:false, error:"字段名: 原因"}`。

## 4. config.json schema（最终形态）

现有全部键保持不变（detection/schedule/webui/monitors/on_live_command/on_offline_command），新增：

```json
"nas": { "enabled": false, "protocol": "smb", "host": "", "port": 445,
         "share": "", "username": "", "password_ref": "keychain:douyin-nas",
         "mount_point": "/Volumes/douyin-archive", "root_dir": "录播" },
"recorder": { "output_dir": "" }   // 空串 = {BASE}/recordings，运行时解析
```

- **向后兼容规则**：任何代码读 config 必须容忍键缺失并用上述默认值；启动时 merge 默认值后落盘一次。
- **密码永不落盘**：password_ref 是钥匙串引用，密码本身只存 `security add-generic-password -U -s douyin-nas`。

现有：`{name} {anchor} {room_id} {sec_uid} {room_url} {stream_url}`；新增：`{BASE}`（B1）。下播 ctx 追加 `output_dir`（C2）。

## 7. 代码风格（全阶段统一）

- 中文 docstring/日志；日志格式 `[YYYY-MM-DD HH:MM:SS] 消息`（沿用 monitor.log）。
- 文件写入一律 tmp + `os.replace`；JSON `ensure_ascii=False, indent=2`。
- 子进程：既有模板保持 shell=True；新增代码一律列表参数，网络/IO 15s 超时，异常必须捕获并记日志。
- 前端：只用现有 CSS 变量与组件类（.card/.field/.btn/.toast/.nav-item/.view），原生 JS，不引入任何库。

## 8. 上下文预算纪律（每个子智能体都必须遵守）

- **只读本任务书指定的文件**，禁止"顺便"阅读其它模块全文（需要时用 grep 定位后只读相关行段）。
- 验证命令输出若超过 30 行，先管道截断再查看（如 `| tail -20`）。
- 修复循环同一问题 ≤3 次，仍失败即停下报告，不得盲目重试。
